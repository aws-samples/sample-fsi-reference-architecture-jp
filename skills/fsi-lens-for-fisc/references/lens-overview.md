# FSI Lens for FISC の概要と構造

本ファイルは、AWS Well-Architected フレームワーク FSI Lens for FISC（以下、FSI Lens）の目的・構造・前提を、出典ドキュメント（README.md）に基づき整理したものである。

## Well-Architected フレームワークと本レンズの目的

AWS Well-Architected フレームワークの目的は、AWS でシステムを構築する際の選択肢の長所と短所を理解できるように支援することである。フレームワークを使用することで、信頼性が高く、セキュアかつ効率的で、コスト効率に優れたシステムをクラウド内で設計・運用するためのアーキテクチャ上のベストプラクティスを学ぶことができる。フレームワークは、アーキテクチャをベストプラクティスに照らし合わせて一貫的に測定し、改善すべき領域を特定する手段を提供する。

AWS Well-Architected フレームワークは一般的にすべてのタイプのワークロードに対応するよう設計されている。コンテキストに基づくアドバイスを提供するため、AWS は 2017 年より Well-Architected「レンズ」の作成を開始した。

「AWS Well-Architected フレームワーク FSI Lens for FISC」では、FISC 安全対策基準に沿って、回復力・セキュリティ・運用パフォーマンスを促進する金融サービス業界（FSI）のワークロードを設計、デプロイ、運用する方法に焦点を当てている。

## FISC 安全対策基準・解説書との関係

日本の金融機関における業界標準の一つとして広く認知・活用されているものとして、1985 年 12 月に財団法人金融情報システムセンター（FISC）により金融機関等の自主基準として策定された「金融機関等コンピュータシステムの安全対策基準・解説書」（FISC 安全対策基準・解説書）が挙げられる。FISC 安全基準・解説書は、システムアーキテクチャおよび運用に関する指針として多くの金融機関によって活用されている。また、金融庁の監督指針でも、主要行、中小・地域金融機関等がシステムリスクならびにセキュリティ対策を検討する上での参考文書としてあげられるなど、日本の金融機関における業界標準の一つとして広く認知・活用されている。

金融サービス業界の特性に依存しない一般的なベストプラクティスについては、AWS Well-Architected Framework も併せて参照すること。FISC 安全対策基準・解説書の各実務基準において参照すべき AWS Well-Architected Framework、および本 FSI Lens については、`fisc-mapping.md` の対応表を参照する。

## 重要な前提・注意事項

- FISC 安全対策基準には適合制度がない。よって本レンズが適合を保証するものではない。業務アプリケーションを含めて各社での安全対策基準のチェックを実施することを前提に本レンズを利用すること。
- 2025 年 3 月に公表された FISC 安全対策基準・解説書の第 13 版では、AI・生成 AI の利用が急速に拡大していることを踏まえ、そのリスク対応のために新たな AI の安全対策に関する基準項目が新設された。
  - AWS は、機械学習システム全般に対して「AWS Well-Architected Framework Machine Learning Lens」を提供しており、ML ライフサイクルにおける設計・運用のベストプラクティスを示している。
  - AWS は 2025 年 4 月に「AWS Well-Architected Framework Generative AI Lens」を発表し、生成 AI ワークロードの設計、デプロイ、運用に関する包括的なガイダンスを提供している。
  - 金融機関が AI システムを構築・運用する際には、FISC 安全対策基準の AI 関連要件への対応手段の 1 つとして、従来の ML ワークロードには Machine Learning Lens を、生成 AI ワークロードには Generative AI Lens を活用することで、それぞれの技術特性に応じた最新のベストプラクティスに基づいた安全で効率的なシステムの実現が期待できる。

## 本レンズの柱（構造）

FSI Lens は 3 つの柱で構成される。各柱は FISC で始まる「質問」（FISCOPS / FISCSEC / FISCREL）と、それに紐づくベストプラクティス（-BPnn）を持つ。各ベストプラクティスは対応する FISC 実務基準番号（実 N）を明示する。

- 運用上の優秀性の柱 → `operational-excellence.md`
- セキュリティの柱 → `security.md`
- 信頼性の柱 → `reliability.md`

# 金融業界での生成 AI ユースケース（ケーススタディ概要）

金融機関における生成 AI 活用の具体的なユースケースを紹介する。Amazon Bedrock を
中心とした AWS サービスを活用した構成例と実装サンプルを含む。

本ケーススタディは、以下の 4 つのユースケースで構成される。各ユースケースは、
金融サービスにおける異なる業務課題に対応する。

- **[文書・コンテンツ審査（document-review / RAPID）](document-review.md)** —
  Human in the Loop による大量文書審査の効率化。
- **[ロールプレイ（ai-roleplay）](ai-roleplay.md)** — AI が演じる顧客との音声対話で
  営業スキルを向上させる研修システム。シナリオ作成の詳細は
  [金融シナリオ作成手順書](ai-roleplay-scenario-guide.md) を参照。
- **[契約書業務アシスタント（contract-assistant-agent）](contract-assistant-agent.md)** —
  スーパーバイザー + 専門エージェントのマルチエージェント構成による契約業務支援。
- **[ATM 不正検知（高齢者電話利用）（cctv-fraud-detection）](cctv-fraud-detection.md)** —
  Amazon Nova による監視カメラ映像のマルチモーダル解析で詐欺を検知。

## 横断的な特徴と設計思想

いずれのユースケースも中核に **Amazon Bedrock** を据え、それを補完する AWS サービス
群で構成される。各ユースケースには公開サンプル実装が存在する。

金融サービスにおける意義として、以下の共通課題への対応がある。

- 膨大な手作業による文書審査の負荷軽減。
- 一貫した営業品質とコンプライアンス遵守（適合性原則、金融商取法に基づく説明義務など）の
  実現。
- 契約業務の効率的な処理。
- 顧客（特に高齢者）を詐欺被害から保護すること。

共通するビジネスドライバーは次のとおりである。

- 業務効率化：24 時間対応、定型業務の自動化。
- 品質標準化：担当者ごとのばらつきの解消。
- コスト削減：人件費の削減。
- 透明性・説明責任：AI の判断根拠を明示し、説明可能性と監査対応を支援する。

## 共通アーキテクチャ要素

複数のユースケースで共通して利用される主な AWS サービスは以下である。

- **Amazon Bedrock**：生成 AI の基盤。LLM のホスティング、マルチエージェント
  コラボレーション、ガードレール、Amazon Nova によるマルチモーダル解析などを提供する。
- **AWS Lambda / Amazon API Gateway**：サーバーレスの処理層と REST API。
- **Amazon S3 / Amazon DynamoDB**：文書・動画・シナリオデータ・評価結果・チェックリスト・
  メタデータなどのデータ層。
- **Amazon CloudFront**：Web UI（ブラウザベースの操作画面）の配信。

各ユースケースの詳細なアーキテクチャ、処理フロー、使用サービスは、それぞれの
リファレンスファイルを参照すること。

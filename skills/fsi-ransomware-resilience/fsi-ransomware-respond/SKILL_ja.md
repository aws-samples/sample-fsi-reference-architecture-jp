# 金融機関向けランサムウェア対策:対応(Respond)(プレースホルダ)

本スキルは、金融サービス業界の組織向けランサムウェア対策における「対応(Respond)」フェーズ(証拠保全・隔離・フォレンジックベンダ連携等)のプレースホルダです。

**本スキルは現時点では未実装です。** 利用可能なフェーズスキルの確認には `fsi-ransomware-overview` を使用してください。

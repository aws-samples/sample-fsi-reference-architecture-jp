# 金融機関向けランサムウェア対策 Agent Skills（fsi-ransomware-resilience）

AWS 上でのランサムウェア対策の検討を支援する、金融サービス業界向けの Agent Skill 群です。バックアップ・データ保護の設計から、脅威の検知、有事の対応・復旧、組織的な体制づくりまで、ランサムウェア対策が扱う領域を体系的にカバーします。

## このパッケージで得られるもの

ランサムウェアによる侵入を100%防ぐことは現実的に困難です。侵入を前提に、いかに被害を封じ込め、迅速に事業を復旧できるかが、金融機関としての信頼性を左右します。本パッケージは、この考え方に立って、対策の検討・設計・評価を次の3つの形で支援します。

- **AIエージェントとのチャット形式による対話的なガイダンス**: 相談内容をヒアリングしながら、AWS のベストプラクティスおよびソリューションアーキテクトが蓄積した知見に基づく設計・評価の観点を提示します。
- **自動生成されるレポート（HTML / Markdown）**: 設計提案や評価結果を、レポート形式でまとめて出力します。社内での共有・検討資料としてそのまま活用できます。
- **段階的な導入ロードマップ（短期・中期・長期）の提示**: 対策を一度に完成させるのではなく、段階を踏んで実現していくための優先順位付けを提示します。

利用にあたって専門的な前提知識は必須ではありません。エンジニア・インフラ担当者はもちろん、リスク管理部門、コンプライアンス部門、CSIRT・セキュリティ運用担当など、ランサムウェア対策の検討に関わる幅広い立場の方が、それぞれの関心に応じて活用できます。

## 全体像（Ransomware Resilience Framework）

本パッケージは、入口となる序章（Overview）を含めて6つのスキルで構成されます。実際の対策検討は、以下5つのフェーズスキルが担います。

| フェーズ | スキル名 | 概要 | 提供状況 |
|---|---|---|---|
| 序章（Overview） | `fsi-ransomware-overview` | 相談内容に応じた各フェーズへの案内・全体像の説明 | 利用可能 |
| 保護（Protect） | `fsi-ransomware-protect` | バックアップ・データ保護のアーキテクチャ設計・評価 | 利用可能 |
| 検知（Detect） | `fsi-ransomware-detect` | サービス影響・攻撃の検知および分析 | 利用可能 |
| 対応（Respond） | `fsi-ransomware-respond` | 検知後の隔離・証拠保全、フォレンジック対応への橋渡し | 今後リリース予定 |
| 復旧（Recover） | `fsi-ransomware-recover` | バックアップからの復旧手順、感染チェック、サービスの段階的復帰 | 今後リリース予定 |
| 組織対応（Organization） | `fsi-ransomware-organization` | 有事の組織体制、社内外コミュニケーション、規制当局への報告等 | 今後リリース予定 |

どのフェーズから相談すべきか分からない場合は、まず序章（`fsi-ransomware-overview`）に相談してください。相談内容に応じて、適切なフェーズへ案内されます（具体的な相談の始め方は「使い方」章を参照してください）。

### 保護（Protect）

バックアップ・データ保護環境のアーキテクチャ設計、既存環境の評価を支援します。マルチアカウントによる役割分離戦略、AWS Backup を中心としたバックアップアーキテクチャ、イミュータブル化（Vault Lock / S3 Object Lock）と暗号化、IAM / KMS / SCP によるポリシー設計、マルウェアスキャン戦略、フォレンジック対応に備えたログ収集・保護、バックアップ運用の監視・監査、オンプレミス環境のバックアップ統合を扱います。

### 検知（Detect）

被害・脅威の検知と、検知した事象の分析を支援します。サービス影響の検知（リソース監視・サービス監視・外形監視・業務指標監視）、セキュリティ攻撃の検知（Amazon GuardDuty の保護プラン、サードパーティ製品）、アラートを起点とした原因切り分け、収集済みログを活用した分析・調査（Amazon Detective、SIEM on Amazon OpenSearch Service）、検知・分析の集約・委任管理を扱います。

### 対応（Respond）・復旧（Recover）・組織対応（Organization）

いずれも今後リリース予定です。現時点では、序章（Overview）に相談すると、各フェーズが扱う予定の内容について案内を受けられますが、具体的な設計・評価の相談には対応していません。

## 使い方

### 配置

以下のディレクトリ構造で配置します。各スキルフォルダを、ご利用の環境（Kiro 等）が Agent Skill として読み込むディレクトリ（例: `.kiro/skills/`）に配置してください。

```
skills/
└── fsi-ransomware-resilience/
    ├── fsi-ransomware-overview/
    ├── fsi-ransomware-protect/
    ├── fsi-ransomware-detect/
    ├── fsi-ransomware-respond/
    ├── fsi-ransomware-recover/
    └── fsi-ransomware-organization/
```

各スキルフォルダには、スキル本体（`SKILL.md` および日本語版 `SKILL_ja.md`）と、参照情報（`references/`）、レポート自動生成用のテンプレート（`report-templates/`。保護・検知フェーズのみ）が含まれます。

### 呼び出し方

各スキルは、ユーザーの発言内容に応じて自動的に発動します。特定のスキルを明示的に指定する必要はなく、自然な言葉で相談を始めてください。

相談したい領域やサービスがまだ具体的に決まっていない場合は、「ランサム対策設計について相談したい」のように、広めの問いかけから始めてください。これにより序章（`fsi-ransomware-overview`）が自然に発動し、全体像の説明や、相談内容に応じた適切なフェーズへの案内を受けられます。一方、相談内容が特定のフェーズに明確に該当する場合（例: 「AWS Backup を使ったイミュータブルなバックアップ環境を設計したい」「Vault Lock の設計について相談したい」）は、該当するスキルが直接応答することもあります。どちらの入り方でも、必要なヒアリングを経て設計提案・評価・ガイダンスに進みます。

### AWS Documentation MCP サーバーの利用（推奨）

本パッケージは、AWS の公式ドキュメントを参照して回答の正確性を高める設計になっています。利用にあたっては、AWS Documentation MCP サーバーを事前にセットアップしておくことを推奨します。

セットアップ手順は、ご利用の環境（Kiro 等）の MCP サーバー設定方法に従ってください。AWS Documentation MCP サーバー自体の詳細は以下の公式ドキュメントを参照してください。

- [AWS Documentation MCP Server（公式ドキュメント）](https://awslabs.github.io/mcp/servers/aws-documentation-mcp-server)

## 利用にあたっての注意点

- 本パッケージが提示するガイダンス・設計提案・評価結果は、AIエージェントによる対話を通じて生成されます。案内の精度は、利用するAIモデルの能力に依存する部分があり、また内容の正確性を完全に保証するものではありません。提示された内容は設計・評価を進めるための有用な出発点として活用し、実際に対策を実施する際の最終判断は、利用者自身の確認・検討のもとで行ってください。
- 本パッケージが提供する設計提案・評価結果は、AWS のベストプラクティスに基づく一般的な検討の出発点です。個々の組織の規制・コンプライアンス要件への適合性については、各組織の規制対応・コンプライアンス部署による確認を経てください。
- AWS の各サービスの仕様・提供機能は継続的に更新されます。本パッケージは公式ドキュメントの参照を前提とした設計になっていますが、重要な意思決定の際は、AWS 公式ドキュメントで最新の情報を確認してください。
- 対応（Respond）・復旧（Recover）・組織対応（Organization）は今後リリース予定であり、現時点では具体的な設計・評価の相談には対応していません。
